# Marlène Party

User brief is the visual source of truth. The skill search returned no suitably verified party style; these decisions are authored from the brief with UI/UX Pro Max general accessibility guidance.

- Warm ivory #fffaf2, deep aubergine #392938, coral #f87979, lilac #d9c9f4, butter #ffdf86, mint #c9e6d5.
- Fredoka headings and Nunito body, self-hosted fonts. Rounded bold type and plenty of breathing room.
- Hand-drawn SVG birthday cake and sticker details; subtle offset shadows, outlined cards, cream dotted paper.
- One obvious primary action per mobile view. Persistent game status and visible validation. Touch targets at least 44px.
- Normal text uses deep ink; coral and pastel fills always have dark ink. White text only on dark controls.
- No hover-only behavior; visible keyboard focus, labeled fields, pressed/selected states; reduced motion.
- Guests: distraction-free; host: useful controls; Marlène: lilac/crown; projector: very large text and room code.
